# 镜头选型四要素计算器

给机器视觉项目做**相机 + 镜头初选**的小工具：输入视野、工作距离、景深、精度要求，输出可落地的相机/镜头组合、光圈、景深与衍射校验。

- 🌐 **在线版（免安装）**：<https://yooz1206.github.io/lens-selector/>
- 🐍 命令行版：`lens_selector.py`，只用标准库，Python 3.9+
- 🎯 默认场景：**0.1 mm 划痕检测**

## 这个工具在算什么

机器视觉光学系统最基本的四个参数是**视野 FOV、分辨率、工作距离 WD、景深 DOF**（放大倍率只是派生量）：

| 要素 | 输入 | 落到的计算 |
|---|---|---|
| ① 视野 FOV | 需要覆盖的宽 × 高（mm） | 所需像素 = FOV ÷ 像素精度；放大倍率 m = 靶面 ÷ FOV |
| ② 工作距离 WD | 镜头到物体的距离（mm） | `FOV = 靶面 × (WD − f) / f`，反解可用焦距 |
| ③ 景深 DOF | 物体高度差 + 定位误差（mm） | `DOF ≈ 2·N·c·(1+m)/m²`，决定光圈上限 |
| ④ 分辨率 | 最小缺陷尺寸、每缺陷像素数 | 像素精度 ≤ 缺陷 ÷ 像素数 |

0.1 mm 划痕、按 3 px 覆盖：

```
像素精度 ≤ 0.1 / 3 = 0.0333 mm/px
100 × 80 mm 视野 → 3000 × 2400 = 7.2 MP
测量不确定度 ≈ ±0.033 mm（±1 px）
```

> 1 px 只能“看见”，2–3 px 检出，3–5 px 才适合量宽度。若 0.1 mm 是**公差**，用 4–5 px 或换远心镜头。

## 在线版

打开 <https://yooz1206.github.io/lens-selector/>，左侧改四要素，右侧实时重算。支持 URL 预填：

```
?fovW=120&fovH=75&wd=200&depth=6.1&defect=0.05&pxd=1&margin=0
```

页面会给出：

1. 像素精度上限、最少像素、最少 MP；
2. 每台相机的像素精度与 `px / 缺陷`（含 3px 门槛线），直接判“通过/不足”；
3. 满足全部约束的相机 + 镜头组合，含实际视野、景深、衍射占比、评分；
4. **初筛通过但没有镜头组合时的原因**（例如 WD 处没有镜头能覆盖该视野，或 8mm 拍得下但像素不够）；
5. 远心镜头（测量级）对比；
6. 不同视野下的像素需求对照。

## 命令行

```bash
python lens_selector.py                      # 交互式问答
python lens_selector.py --demo --sweep       # 演示场景
python lens_selector.py --fov 120x75 --wd 200 --depth 6.1 \
                        --defect 0.05 --px-per-defect 1 --margin 0
python lens_selector.py --selftest           # 11 项公式自检
```

输出控制台报告，并生成 `reports/report.html`、`report.md`、`report.json`。

| 参数 | 含义 | 默认 |
|---|---|---|
| `--fov WxH` | 视野 mm | 100x80 |
| `--wd` | 工作距离 mm | 400 |
| `--depth` | 景深要求 mm | 5 |
| `--defect` | 最小缺陷 mm | 0.1 |
| `--px-per-defect` | 每个缺陷的像素数 | 3 |
| `--margin` | 视野余量，0.5 = +50% | 0 |
| `--coc-px` | 弥散圆 = n 个像元 | 2 |

Windows 控制台乱码：`chcp 65001`，或设 `PYTHONIOENCODING=utf-8`。

## 公式

```
m     = f / (WD − f)              薄透镜近似
FOV   = 靶面尺寸 / m
px    = 像元 / m                  (mm/px)
DOF  ≈ 2·N·c·(1+m)/m²             c = CoC 像素数 × 像元
d_airy = 2.44·λ·N·(1+m)           λ = 0.55 µm
f_defect = 1/(2·缺陷宽度·m)        缺陷在像面的空间频率 (lp/mm)
```

选镜头时先卡：像圈 ≥ 靶面对角线、WD ≥ MOD、视野覆盖；再卡像素精度与景深；最后按像素余量、景深余量、衍射、镜头解析力、成本、快门类型打分。

## 内置器材库

- **相机 7 款**：1.3 MP ~ 20 MP，1/2"、1/1.8"、2/3"、1/1.7"、1"，全局/卷帘，GigE/USB3
- **FA 镜头 17 支**：8–50 mm，2/3" 与 1" 像圈，含 200 lp/mm 高解析系列
- **远心镜头 8 档**：0.05×–1.0×，WD 100–400 mm

这些是**同级通用规格**，用于把方案算通；采购前请用厂商 datasheet 复核 MOD、畸变、MTF 与像圈。

## 局限

- 薄透镜近似，实际镜头的有效焦距、主面位置、畸变会带来几个百分点偏差；
- 划痕是低对比度缺陷，**打光**（低角度暗场/同轴）往往比相机更决定成败；
- 不覆盖运动模糊、畸变校正与标定误差；测量级应用建议远心 + 标定板。
